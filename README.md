# Skyline

An original luxury-residential showcase built with Next.js App Router, TypeScript, a procedural Three.js tower, and a SQLite-backed property/enquiry API.

## Status

Project bootstrap. Implementation, automated verification, and measured performance reports are added incrementally. No production deployment or performance result is claimed yet.

## Development

1. Use Node.js 22 LTS (Next.js requires Node.js 20.9 or newer).
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env` and review the values.
4. Run migrations and seed data with `npm run db:migrate && npm run db:seed`.
5. Start with `npm run dev`.

See the architecture and operational notes added as the implementation progresses.
